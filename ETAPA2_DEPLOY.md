# Etapa 2 — acabamento visual

Esta entrega moderniza o frontend sem alterar rotas ou contratos do backend.

## Principais mudanças

- identidade visual AgendaPro;
- menu lateral para desktop e menu móvel;
- dashboard e indicadores redesenhados;
- tela de login com aparência comercial;
- filtros, botões, campos e superfícies padronizados;
- cartões de clientes e agendamentos refinados;
- menu de ações com melhor hierarquia;
- correção da busca quando o cliente não possui sobrenome.

## Publicação

1. Preserve os arquivos `.env` reais.
2. Substitua os arquivos do projeto pelos desta versão.
3. Execute `npm install`, `npm test` e `npm run build` dentro de `frontend`.
4. Envie para o GitHub e acompanhe o deploy da Vercel.

O backend e o banco não receberam alterações nesta etapa.

## Teste rápido

Confira login, navegação em desktop e celular, criação e edição de agendamento,
cadastro de cliente, filtros, visualizações e todas as opções do menu de três
pontos.
